## 2. 학습·평가 데이터

| 항목 | 방침 |
|---|---|
| 실제 피해자 통화 녹음 | **일절 사용하지 않는다.** 공개 연구용 데이터셋과 자체 합성물만 |
| 원본 데이터 재배포 | 하지 않는다. **URL + SHA-256만 코드에 고정**하고 각자 받아 재현하게 한다 (`src/phishstress/data/registry.py`). `data/`는 gitignore 대상 |
| 업스트림 저장소 전체 클론 | 하지 않는다. 필요한 CSV 파일 **하나만** raw URL로 받는다. 원 저장소에는 작성자가 실수로 커밋한 클라우드 서비스 계정 키 파일이 포함되어 있어, 전체를 벤더링하면 그 자격증명까지 우리 저장소에 딸려 들어온다 |
| 합성 음성 | 공개 코퍼스 화자 또는 본인 음성만. 실존 인물 사칭 목적 제작 금지 |
| AI 기본법 준수 | 자체 생성 합성 음성에 메타데이터 표시를 삽입한다 (제31조 제2항 비가시적 표시 방식 준용, 2026-01-22 시행) |

## 3. 적대적 변형 생성기에 대한 제한

KO-VP-Stress 축 A는 판별기를 속이는 문구 변형을 만든다. 오용 가능성이 있으므로 설계로 제한한다.

- **신규 사기 시나리오를 생성하지 않는다.** 이미 라벨이 붙은 공개 데이터의 **표면형만 변형**한다.
- 자유 텍스트를 입력받아 "더 그럴듯한 피싱 문구"를 만들어주는 인터페이스는 제공하지 않는다.
- 변형 규칙은 공개한다 — 방어 연구의 재현성이 공격 편의보다 중요하다고 판단했다.
- 생성 결과물은 평가 목적으로만 저장소에 포함한다.

## 4. 더미 판별기의 키워드 목록에 대하여

`detectors/dummy.py`의 `KeywordTextDetector`는 금융감독원·경찰청 **공개 안내문 수준의
일반 어휘**만 사용한다. 실제 사기 대본이나 비공개 수사 자료는 포함하지 않는다.
이 판별기는 Day 5에 학습 모델로 교체될 자리표시자다.

## 5. 법적 맥락

- **통신비밀보호법**: 본 시스템은 통화 당사자 단말에서 동작하는 것을 전제로 설계했다.
  제3자 통화를 가로채는 용도가 아니며, 오디오 비저장 설계가 이를 뒷받침한다.
- **정보통신망법 개정** (2026-07-07 시행): 판별 결과의 근거를 남길 수 있어야 한다는 요구가
  `contributions` 필드(판별기별 점수·신뢰도·유효 가중치)로 반영되어 있다.
- **AI 기본법 제31조 제2항** (2026-01-22 시행): 자체 생성 합성 음성에 표시 의무를 준용한다.

## 6. 모델 배포 시 제한

학습된 판별기 가중치를 공개할 경우, 회피(evasion) 목적 재사용을 라이선스로 금지한다.
다만 **라이선스만으로는 실효성이 없다**는 점을 인정한다. 그래서 이 프로젝트는
회피 가능성을 숨기는 대신 **정량화해서 공개하는 쪽**을 택했다 — 어느 변형에 얼마나
약한지 스스로 밝히는 것이 방어 연구에 더 도움이 된다고 판단했다.
